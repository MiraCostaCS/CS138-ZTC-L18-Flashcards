# Lab 18 - Flashcards + GUI

This lab builds a multi-page GUI flashcard study application using Tkinter.

Step 1: Enable File I/O in your CodeHS settings before starting this lab.

Step 2: Build a first page that shows a menu with options to edit flashcards, study flashcards, or exit the app.

Step 3: Use a class with an __init__(self, parent, root) method, and use Frame and Label widgets to organize each page of the app.

Step 4: Build an edit page that lets the user add, update, or remove flashcards, saving them to a file.

Step 5: Build a study page that loads flashcards from the file and lets the user flip through and review them.

Step 6: Wire up navigation between pages so the user can move between the menu, edit page, and study page.

Make sure your code follows Python style conventions and includes clear comments explaining each class, page, and function.
